# DESI Legacy Imaging Surveys DR10 (`ls10`)

<!-- generated:survey-page -->

The DESI Legacy Imaging Surveys Data Release 10 (DR10) is a major public release of wide-field optical imaging coadds combining observations from the Dark Energy Camera (DECam) on the 4-metre Víctor M. Blanco Telescope at Cerro Tololo Inter-American Observatory (CTIO). DR10 covers the southern sky across optical broadbands $g, r, i, z$, reaching $5\sigma$ point-source depths of $g \approx 24.7$, $r \approx 23.9$, and $z \approx 23.0$ AB mag.

In MOSAICS, `ls10` is configured exclusively as an image cutout survey. While DR11 provides the primary photometric catalogue and optical cutouts in $g, r, z$, DR10 supplies cutouts across all four bands ($g, r, i, z$), critically providing the $i$-band cutouts that the DR11 Legacy Survey Viewer stack does not serve. Cutouts are served via the Legacy Survey Viewer (`layer: ls-dr10`) in native nanomaggies. CDS HiPS layers for DR10 are defined in the configuration but disabled pending validation against the Viewer’s photometric scale.

## Configuration

### The shipped file

Source: `defs/surveys/ls10.yaml`

```yaml
# DESI Legacy Imaging Surveys DR10 -- cutouts only.
#
# The catalogue takes its Legacy Survey photometry from DR11; DR10 is here for
# its fourth band, which DR11's Viewer layer does not serve.

survey_slug: ls10
name: DESI Legacy Imaging Surveys DR10

# max_mag: 23.0 (max_mag_band: z). As ls11 -- 5 sigma point source, AB; DR10
# g/r/z 24.7/23.9/23.0.
cutout:
  - adapter: lsv          # VERIFIED LIVE 2026-08-25
    adapter_params:
      layer: ls-dr10
      bands: griz
    bands: [g, r, i, z]
  # CDS publishes DR10 as four single-band HiPS as well, all with FITS
  # tiles (MOCServer, 2026-09-05). They fill the same four columns as the
  # Viewer stack above, so the router could pick either -- but disabled
  # until one is checked against the other, because `pixel_unit:
  # nanomaggy` is a statement about the *Viewer's* output and the HiPS
  # build states no scale of its own.
  - adapter: hips
    adapter_params:
      hips_id: CDS/P/DESI-Legacy-Surveys/DR10/g
    bands: [g]
    enabled: false
  - adapter: hips
    adapter_params:
      hips_id: CDS/P/DESI-Legacy-Surveys/DR10/r
    bands: [r]
    enabled: false
  - adapter: hips
    adapter_params:
      hips_id: CDS/P/DESI-Legacy-Surveys/DR10/i
    bands: [i]
    enabled: false
  - adapter: hips
    adapter_params:
      hips_id: CDS/P/DESI-Legacy-Surveys/DR10/z
    bands: [z]
    enabled: false

photometric_system:
  pixel_unit: nanomaggy
  pixel_unit_note: As ls11 -- Legacy Survey coadds are nanomaggies by construction.
  # DR10 and DR11 are the same DECam filter set on two data releases, so the
  # passbands -- and therefore the pivot wavelengths a flux calibration needs
  # -- are ls11's. The releases differ; the filters do not.
  borrow_filters: ls11
```

## Data served by the archive

- **Cutout-only role:** DR10 does not participate in target selection or catalogue crossmatch; its role in MOSAICS is providing $g, r, i, z$ image cutouts (especially $i$-band) complementary to DR11.
- **Nanomaggy pixel units:** Coadd cutouts extracted via the Legacy Survey Viewer are natively in nanomaggies, corresponding to a fixed AB magnitude zero point of 22.5 ($1\,\text{nanomaggy} = 3.631\,\mu\text{Jy}$).
- **Filter profile borrowing:** DR10 uses the same DECam instrument and filter set as DR11. Rather than duplicating filter definitions, `ls10` borrows its filter curves and pivot wavelengths directly from `ls11` (`borrow_filters: ls11`).
- **Photometric depth:** Point-source $5\sigma$ depths are $g = 24.7$, $r = 23.9$, $z = 23.0$ AB mag, matching the southern DECam depths of DR11.
