mosaics-spectrum — 1D Spectrum Extraction¶

mosaics-spectrum (uv run -m mosaics.cli.spectrum) downloads variable-length 1D spectra across spectroscopic surveys and stores them as parallel Arrow large_list columns ({slug}_flux, {slug}_error, {slug}_wavelength, {slug}_mask) in a Lance dataset.

Subcommands¶

  • full: Fetch spectra across multiple spectroscopic surveys defined in --config (defs/full.yaml) into a single Lance dataset.

  • Per-survey subcommands (2dfgrs, 6dfgs, desi1, euclidq1, hasp, lamost11, sdss17): Fetch spectra for a single spectroscopic survey using its configured adapter(s).

Examples¶

$ uv run -m mosaics.cli.spectrum sdss17 -t test/objects_sample_1k.csv -o sdss17_spectra.lance --snr-floor 2.0
$ uv run -m mosaics.cli.spectrum desi1 -t test/objects_sample_1k.csv -o desi1_spectra.lance --via healpix
$ uv run -m mosaics.cli.spectrum full -t test/objects_sample_1k.csv -o spectra_full.lance --config defs/full.yaml --snr-floor 2.0

Command-line reference¶

Entry points: mosaics-spectrum or uv run -m mosaics.cli.spectrum

Top-level options¶

mosaics.cli.spectrum [-h]
                            {2dfgrs,6dfgs,desi1,euclidq1,hasp,lamost11,sdss17,url,template,full}
                            ...

mosaics-spectrum 2dfgrs¶

2dF Galaxy Redshift Survey spectra, via template.

mosaics.cli.spectrum 2dfgrs [-h] --targets TARGETS [--ra-col RA_COLUMN]
                                   [--dec-col DEC_COLUMN] [--id-col ID_COLUMN]
                                   [--limit LIMIT] [--sort {native,key}]
                                   [--key-col KEY_COLUMNS [KEY_COLUMNS ...]]
                                   [--url-template URL_TEMPLATE]
                                   [--format {desi,fits,generic,hasp,lamost,sdss,votable}]
                                   [--prefix PREFIX]
                                   [--arrays {flux,error,wavelength,mask} [{flux,error,wavelength,mask} ...]]
                                   --output OUTPUT [--dtype DTYPE]
                                   [--max-samples MAX_SAMPLES]
                                   [--snr-floor SNR_FLOOR] [--resume]
                                   [--no-stats] [--retry-failed]
                                   [--proxy PROXY]
                                   [--max-per-origin MAX_PER_ORIGIN]
                                   [--retries RETRIES] [--timeout TIMEOUT]
                                   [--proxy-stats-url URL] [--wandb]
                                   [--wandb-project WANDB_PROJECT]
                                   [--wandb-entity WANDB_ENTITY]
                                   [--wandb-name WANDB_NAME]
                                   [--batch-size BATCH_SIZE] [--no-progress]
                                   [--log-level {DEBUG,INFO,WARNING,ERROR,CRITICAL}]
                                   [--status-interval STATUS_INTERVAL]
                                   [--option KEY=VALUE]

Columns identifying a spectrum. Defaults to whatever the chosen backend needs, so this is only for a table that names them unusually.

None

—

Format string built from target-table columns, or one of: 2dfgrs, lamost-dr11, sdss-eboss, sdss-legacy, sdss-v.

desi, fits, generic, hasp, lamost, sdss, votable

Reader used to decode a response. Defaults to the source’s own.

--prefix PREFIX

None

—

Column-name prefix, e.g. “sdss” gives sdss_flux. Defaults to the source name.

--arrays ARRAYS

None

flux, error, wavelength, mask

Which of a spectrum’s arrays to store. Defaults to the source’s own set.

--output, -o OUTPUT

required

—

Destination Lance dataset.

--dtype DTYPE

float32

—

Sample dtype. Default: float32.

--max-samples MAX_SAMPLES

2000000

—

Reject a spectrum longer than this. Default: 2000000.

--snr-floor SNR_FLOOR

3.0

—

Signal-to-noise a sample must reach to be marked usable in the mask, where the survey publishes an error (default: 3). Worth lowering: at 3 the mask excludes most of a faint object’s continuum, so a model trained on the mask sees little but emission lines. The value used is recorded in the dataset metadata.

--resume

false

—

Continue an existing dataset, skipping spectra already present.

--no-stats

true

—

Skip the QA metric columns. Makes resume read samples instead.

--retry-failed

false

—

With –resume, fetch again the spectra recorded in the failure sidecar.

--proxy PROXY

None

—

Proxy URL, e.g. http://127.0.0.1:8888 to route through a mosaics proxy pool. HTTPS_PROXY is honoured when this is omitted.

--max-per-origin MAX_PER_ORIGIN

3

—

In-flight requests per host per source IP, which is what an archive actually throttles on. Behind a proxy pool the real ceiling is this times the number of connected workers, read from –proxy-stats-url. Default: 3.

--retries RETRIES

5

—

Attempts per request. Only transient failures consume attempts; a 404 fails immediately. Default: 5.

--timeout TIMEOUT

60.0

—

Per-request timeout in seconds. Default: 60.0.

--proxy-stats-url URL

None

—

URL of a mosaics proxy stats endpoint, e.g. http://127.0.0.1:8889/stats. Read once at startup to learn how many workers are connected, which is what turns –max-per-origin into the real per-host ceiling, and polled per batch for the telemetry panel when –wandb is on. A proxy that cannot be reached is treated as a single source IP.

--wandb

false

—

Log progress to W&B.

None

—

W&B project.

--wandb-entity WANDB_ENTITY

None

—

W&B entity.

--wandb-name WANDB_NAME

None

—

W&B run name.

--batch-size, -b BATCH_SIZE

512

—

Spectra per download-and-append cycle. Default: 512.

--no-progress

true

—

Hide the progress bar.

--log-level LOG_LEVEL

INFO

DEBUG, INFO, WARNING, ERROR, CRITICAL

Logging verbosity.

--status-interval STATUS_INTERVAL

30.0

—

Seconds between [PIPELINE STATUS] blocks, which say how many batches are done and which backends are in flight. A backend can be silent for minutes behind a rate limit, so this is what tells a quiet run from a stuck one. 0 turns them off. Default: 30.

[]

—

Backend option override, repeatable. Escape hatch over a preset.
